# POETools

## Preparing the environment
Create a virtual environment with python's UV package manager:
> pip install uv
> uv venv
Activate it
- Windows:
> .\.venv\Scripts\activate 
- Linux:
> source ./.venv/bin/activate

Install required libs:
> uv sync


## Executing scripts
> python \<**script name**\> \<**script arguments**\>
